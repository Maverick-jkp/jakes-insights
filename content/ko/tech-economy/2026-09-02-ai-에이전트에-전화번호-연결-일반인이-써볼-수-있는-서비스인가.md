AI가 나 대신 전화를 거는 시대가 왔어요. 그것도 사람 목소리로.

2026년 현재, "AI 에이전트에 전화번호 연결"이라는 개념이 조용히 현실이 되고 있어요. 이전까지는 챗봇이나 이메일 자동화 수준이었다면, 지금은 AI가 직접 전화를 걸고 받고, 예약을 잡고, 민원을 처리하는 단계까지 왔거든요. 그런데 여기서 가장 현실적인 질문이 생겨요. "일반인이 써볼 수 있는 서비스인가?"

직접 만들려면 벽이 높아요. [Gpters.org의 분석](https://www.gpters.org/news/post/ai-agent-making-phone-mM54YoxxrzL1IPi)에 따르면, AI 전화 에이전트를 혼자 구축하려면 070 VoIP 번호 계약(최소 2-3주 소요), SIP 서버 설정, STT/TTS 엔진 연동이 동시에 필요해요. 개인이나 소규모 팀이 감당하기엔 너무 많은 게 한꺼번에 걸려 있는 구조죠.

그런데 이걸 하나의 API 호출로 해결하겠다는 서비스들이 나오기 시작했어요. 이 글에서는 지금 실제로 쓸 수 있는 서비스가 뭔지, 진입 장벽은 어느 정도인지, 그리고 일반인 기준으로 현실적인 선택지가 있는지 따져볼게요.

살펴볼 핵심 포인트는 네 가지예요:
- AI 전화 에이전트 구축에 필요한 기술 스택의 실체
- 국내(클로우옵스)와 해외(AgentCall) 서비스 비교
- 비용 구조와 실제 진입 장벽
- 일반인·소상공인 기준 현실적 활용 가능성

---

**In brief:** 2026년 기준, AI 에이전트에 전화번호를 연결하는 인프라는 이미 존재하지만, "일반인"의 정의에 따라 접근성이 크게 달라져요. 비개발자에겐 여전히 설정 장벽이 있고, 개발 경험이 조금이라도 있는 사람이라면 월 2-10만 원 수준에서 실제로 써볼 수 있는 선택지가 생겼어요.

세 가지 핵심 사실:
1. ClawOps는 한국 070 번호를 단일 API 호출로 10초 안에 발급하며, 기존 방식 대비 셋업 시간을 2-3주에서 수 분으로 단축시켰어요.
2. AgentCall은 62개 도구와 31개 언어를 지원하며, 월 $19.99부터 시작하는 유료 플랜에서 분당 $0.035의 통화 단가를 적용해요.
3. 두 서비스 모두 MCP(Model Context Protocol)를 통해 Claude와 연동되며, 일부 기능은 코드 없이도 설정할 수 있어요.

## AI 전화 에이전트, 왜 지금 갑자기 가능해졌나

사실 AI가 음성으로 소통하는 건 오래된 기술이에요. 그런데 왜 지금까지 "일반인이 쓰는" 수준이 아니었냐면, 인프라를 붙이는 과정이 너무 복잡했기 때문이에요.

전화 한 통을 AI가 받으려면 적어도 네 가지가 동시에 맞물려야 해요. 전화번호 자체(통신사 계약), 음성을 텍스트로 바꾸는 STT, 텍스트를 다시 음성으로 바꾸는 TTS, 그리고 실제 전화망에 연결하는 SIP 프로토콜. 이걸 각각 계약하고 연동하는 건 통신사 영업 담당자와 미팅하고, 서류 제출하고, 서버 설정하는 과정을 포함해요. 개인 개발자나 소상공인이 건드리기엔 시간도 비용도 너무 많이 들었죠.

전환점은 두 가지였어요. 하나는 LLM의 실시간 응답 속도가 대화에 쓸 수 있는 수준으로 올라온 것. 다른 하나는 OpenAI Realtime API처럼 음성 입력을 바로 처리하는 API가 등장한 것이에요. 이 두 조각이 맞으면서, 기존에는 통신 인프라 회사만 할 수 있던 걸 소규모 팀이 서비스로 포장해서 제공할 수 있게 됐어요.

국내에서는 Vapi, Retell, Bland 같은 해외 서비스가 한국 070 번호를 지원하지 않는다는 공백을 노린 [ClawOps](https://claw-ops.com/blog/build-phone-bot)가 등장했어요. 해외에서는 [AgentCall](https://agentcall.co/)이 62개 도구와 전화번호, SMS, OTP 추출까지 한 API에 묶어서 제공하기 시작했고요.

MCP(Model Context Protocol)의 확산도 빼놓을 수 없어요. AI 에이전트가 외부 서비스의 기능을 직접 호출하는 표준 방식이 생기면서, 전화 API를 Claude나 Cursor 같은 도구에 붙이는 방식이 단순해졌어요. ClawOps는 25개, AgentCall은 62개 도구를 MCP로 노출해요.

## 실제 서비스 비교: ClawOps vs AgentCall

### 한국 서비스: ClawOps

[ClawOps 블로그](https://claw-ops.com/blog/build-phone-bot)에 따르면, 이 서비스의 핵심 차별점은 하나예요. 한국 070 번호를 API로 발급해준다는 것. 직접 SIP 인프라를 구축하면 1-2주 걸리는 걸 단일 POST 요청으로 10초 안에 처리해요.

기술 스택은 AWS 서울 리전 기반이라 국내 레이턴시가 낮고, SIP/2.0 프로토콜에 SRTP 암호화를 적용했어요. 음성 처리(STT/TTS)는 개발자가 직접 선택하는 구조인데, VITO 엔진(한국어 STT)과 CLOVA Voice(TTS)를 권장해요. 규제 측면에서도 과학기술정보통신부 기준을 따르고 KISA 보안 기준을 준수해요.

베타 가격은 개인 플랜 월 19,000원(아웃바운드 100분, 인바운드 1,000분, 회선 1개), 비즈니스 플랜 월 99,000원(아웃바운드 1,000분, 인바운드 10,000분, 10개 회선)이에요. 3일 무료 체험도 있어요.

### 글로벌 서비스: AgentCall

[AgentCall](https://agentcall.co/)은 접근 방식이 달라요. 전화번호, SMS, OTP 추출, AI 음성통화, 통화 간 메모리를 하나의 API로 묶었어요. Vapi, Retell, Bland에는 없는 "크로스콜 메모리"가 특징인데, 이전 통화 맥락을 다음 통화에 그대로 이어갈 수 있어요.

8개 AI 음성, 31개 언어 자동 감지를 지원하고, 설정은 JSON 블록을 Claude Desktop 설정 파일에 붙여넣는 것만으로 끝나요. Node.js 설치도 필요 없어요.

### 두 서비스 직접 비교

| 기준 | ClawOps | AgentCall |
|------|---------|-----------|
| **지원 번호** | 한국 070 | 미국 번호 (국내 미지원) |
| **월 기본료** | ₩19,000 (개인) | $19.99 (Pro) |
| **통화 단가** | 플랜에 포함 | $0.035/분 (음성) |
| **STT/TTS** | VITO + CLOVA (한국어 최적) | 자체 다국어 (31개 언어) |
| **크로스콜 메모리** | 미언급 | 모든 플랜 포함 |
| **MCP 도구 수** | 25개 | 62개 |
| **설정 난이도** | API 코딩 필요 | JSON 설정으로 가능 |
| **한국 규제 준수** | KISA/과기부 기준 | 미확인 |
| **추천 대상** | 국내 서비스 운영자 | 글로벌 서비스 / 영어권 |

국내 고객을 대상으로 한국어 전화 서비스를 만들어야 한다면 ClawOps가 현실적인 선택이에요. 반대로 영어권 또는 다국어 서비스가 필요하다면 AgentCall의 기능 폭이 더 넓어요.

## 진짜 질문: 일반인이 실제로 쓸 수 있나?

### 비개발자라면

지금 단계에선 어려워요. ClawOps는 POST API 호출, 웹훅 설정, STT/TTS 연동이 필요해요. AgentCall은 JSON 설정 파일을 수동으로 편집해야 하고요. "코드 한 줄 없이"라고 말하기엔 아직 진입 장벽이 있어요.

그래도 방향은 분명히 낮아지고 있어요. AgentCall의 경우 Claude Desktop에 JSON 블록만 붙여넣으면 기본 설정이 끝나는 구조라, 기술 문서를 읽고 따라할 수 있는 수준이라면 시도해볼 만해요. AI에게 설정 방법을 물어가며 진행하는 것도 가능하고요.

### 소상공인·소규모 비즈니스라면

가장 현실적인 수혜 그룹이에요. 치과, 피부과처럼 예약 전화가 많은 곳, 혹은 배송 조회나 반품 안내 전화가 반복되는 소형 이커머스라면 ClawOps 개인 플랜(월 19,000원)으로 24시간 AI 응대가 가능해요. 사람이 받지 못하는 새벽 시간대 예약 전화를 AI가 받아두는 것만으로도 충분한 가치가 있거든요.

### 개발자라면

지금 당장 써볼 수 있어요. MCP 연결은 커맨드 한 줄, 번호 발급은 10초, 아웃바운드 콜은 다섯 줄 코드면 끝이에요. ClawOps 3일 무료 체험으로 실제 통화까지 테스트해보는 게 어렵지 않아요.

**지금 주시해야 할 신호 세 가지:**
- ClawOps 정식 출시 후 가격 변동 여부 (현재 베타가)
- 비개발자용 노코드 UI 제공 시점
- 국내 통신 규제 당국의 AI 전화 에이전트 관련 가이드라인 발표

## 결론: "지금 당장"보다 "지금 시작"이 맞는 표현이에요

AI 에이전트에 전화번호를 연결하는 인프라는 2026년 현재 이미 존재해요. 한국 시장에선 ClawOps가, 글로벌 시장에선 AgentCall이 실제로 쓸 수 있는 선택지로 올라왔어요.

정리하면:
- **개발자**: 지금 바로 테스트 가능, 무료 체험으로 시작
- **소상공인**: 월 2-3만 원 수준에서 현실적 도입 가능, 기술 지원이 필요
- **비개발자**: 노코드 UI가 나오는 시점까지 조금 더 기다리는 게 나을 수 있어요

향후 6-12개월 안에 이 시장에서 주목할 변화는 두 가지예요. 하나는 노코드 설정 흐름의 등장 — 지금의 JSON 편집이나 API 호출을 UI 클릭으로 대체하는 레이어가 반드시 나올 거예요. 다른 하나는 한국 규제 명확화 — AI가 사람 대신 전화를 거는 행위에 대한 가이드라인이 본격적으로 논의될 시점이 다가오고 있어요.

"일반인이 써볼 수 있는가?"라는 질문에 지금 답하자면: 반은 맞고 반은 틀려요. 기술은 준비됐고, 가격도 내려왔어요. 남은 건 경험이에요. 지금 당신 비즈니스에서 반복되는 전화 업무 중 AI가 처리해도 되는 게 몇 퍼센트나 될까요?
