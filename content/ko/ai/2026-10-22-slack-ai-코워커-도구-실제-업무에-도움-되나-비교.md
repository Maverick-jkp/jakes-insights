Slack AI는 채널 요약과 허들 노트처럼 반복 업무를 줄여주는 데 실제로 효과적이에요. 그런데 8월에 출시된 Slack Code는 다른 이야기거든요. 개발팀 외엔 체감 효과가 거의 없어요.

> **핵심 요약**
> - Slack AI 기본 기능(채널 요약, 허들 노트)은 Business+ 플랜($15/user/month) 포함이며, 개발자가 아닌 팀에서도 실제 반복 업무를 줄여줘요
> - 2026년 8월 21일 출시된 Slack Code는 무료지만, Claude Code·GitHub Copilot 등 연동 에이전트 구독비가 따로 붙어서 실질적으론 유료예요
> - Microsoft Teams + Copilot 조합은 미팅·이메일·파일을 한데 묶지만, Copilot Business는 M365 기본 구독에 포함되지 않는 별도 유료 추가 기능이에요
> - 플랫폼 전환 비용(채널 권한 재설정, 외부 파트너 연동 재구성 등)이 구독료 차이보다 클 수 있어요
> - 비개발 직군이라면 Slack AI 기본 기능으로 충분하고, 개발팀이라면 Slack Code + 기존 AI 에이전트 조합이 현실적인 선택이에요

---

## 1. 결론부터: 누가 이기나요?

**비개발 팀에겐 Slack AI 기본 기능이 이겨요.** 채널 요약, 허들 노트, 스레드 요약이 실제 반복 업무를 눈에 띄게 줄여주거든요. 별도 설정 없이 바로 써요.

반면 Slack Code는 개발팀 전용이에요. 4개 에이전트(Claude Code, GitHub Copilot, Devin, Vercel Agent)만 지원하고, 에이전트 구독비가 따로 붙어요. [betwe.tistory.com의 직접 사용 후기](https://betwe.tistory.com/entry/Slack-Code-%EC%A7%81%EC%A0%91-%EC%8D%A8%EB%B3%B4-%ED%9B%84%EA%B8%B0-%EC%9E%A5%EB%8B%A8%EC%A0%90-%EC%B4%9D%EC%A0%95%EB%A6%AC)에 따르면, 에이전트 구독이 없으면 Slack Code는 껍데기예요.

**Slack Code를 선택하지 말아야 할 팀:**
- AI 에이전트 구독이 없는 팀
- 비개발 직군만으로 구성된 팀
- 한국어 UI 지원 여부가 중요한 팀 (미확인)

**이 글에서 비교할 차원:**
- 실제 포함 기능 vs. 추가 비용 구조
- 비개발 vs. 개발팀 적합도
- Slack Code의 실패 지점
- Microsoft Teams Copilot과의 비용 비교

---

> **TL;DR**
> - **Slack AI 기본 기능 쓰세요**, 팀이 채널 기반으로 일하고 회의 정리에 시간을 쓰고 있다면
> - **Slack Code 쓰세요**, Claude Code나 GitHub Copilot 구독이 이미 있고 코드 리뷰를 팀 전체가 함께 보고 싶다면
> - **둘 다 건너뛰세요**, Microsoft 365 에코시스템에 이미 깊이 묶여 있고 Outlook·SharePoint를 핵심으로 쓴다면

## 2. 두 도구의 실체

**Slack AI(기본 기능)**는 Pro($7.25/user/month)부터 채널 요약과 허들 노트를 제공하고, Business+($15/user/month)에서 파일 검색과 더 넓은 AI 검색 범위를 써요. [quasa.io 분석](https://quasa.io/ko/media/slackinya-teamsnyaai-gagyeogboda-gijon-eobmu-muggeumi-meonjeoda)에 따르면 외부 채널 연동은 설정이 상대적으로 쉬운 편이에요. 스레드가 길어진 채널에서 "지난 일주일 요약해줘"가 실제로 작동하는 수준이거든요. 단, Canvas에는 버전 관리가 없어서 문서 협업 도구로는 한계가 있어요.

**Slack Code**는 2026년 8월 21일에 출시된 에이전트 협업 레이어예요. AI 에이전트를 채널에 멘션하면 전용 Code Channel이 자동 생성되고, 작업 완료 후 자동 아카이브돼요. 디자이너나 PM이 코드 diff를 보고 배포 전에 피드백을 줄 수 있는 게 핵심 차별점이에요. 지원 에이전트는 Claude Code(Anthropic), GitHub Copilot(Microsoft), Devin(Cognition), Vercel Agent 네 개뿐이에요. OpenAI ChatGPT 연동은 발표만 됐고 일정은 미정이에요.

## 3. 헤드투헤드 비교

| 비교 항목 | Slack AI 기본 기능 | Slack Code | 승자 |
|---|---|---|---|
| 진입 가격 | Pro $7.25/user/month (기능 포함) | 플랫폼은 무료, 에이전트 구독 별도 | Slack AI |
| 비개발 팀 적합도 | 채널 요약·허들 노트 즉시 사용 | 사실상 개발자 전용 | Slack AI |
| 코드 리뷰 협업 | 지원 없음 | PM·디자이너도 참여 가능 | Slack Code |
| 지원 에이전트 수 | N/A | 4개(2026년 10월 기준) | — |
| 외부 파트너 연동 | 설정 간단 | Code Channel 외부 공유 미확인 | Slack AI |
| 작업 히스토리 | 플랜별 내보내기 제한 | 자동 아카이브 | Slack Code |
| 한국어 UI | 지원 | 미확인 | Slack AI |

**가격에서 결정적 차이가 나요.** Slack Code는 플랫폼 자체는 무료지만, 실제로 쓸 수 있는 에이전트가 전부 구독형이에요. Claude Code만 해도 별도 요금이 붙거든요. "Slack Code는 공짜야"라는 말이 절반만 맞는 이유예요.

**작업 히스토리는 Slack Code의 진짜 강점이에요.** GitHub 히스토리와 달리, 누가 어떤 맥락에서 피드백을 줬는지 채널 단위로 아카이브돼요. 감사 로그가 필요한 팀엔 실제로 유용해요.

**비개발 팀 적합도에서 격차가 커요.** Slack AI 기본 기능은 마케팅팀이든 운영팀이든 바로 써요. Slack Code는 코드 diff를 볼 맥락이 없는 팀엔 의미 없어요.

그럼 Microsoft Teams와 비교하면 어떨까요? [quasa.io에 따르면](https://quasa.io/ko/media/slackinya-teamsnyaai-gagyeogboda-gijon-eobmu-muggeumi-meonjeoda), Teams에서 Outlook 연동 미팅·이메일·파일을 전부 묶고 싶으면 Microsoft 365 Copilot Business가 필요한데, 기본 구독에 포함 안 돼요. 별도 추가 요금이에요. 반면 Slack AI의 채널 요약·허들 노트는 Pro 플랜에 포함돼 있어요.

## 4. 각 도구가 무너지는 지점

**Slack AI 기본 기능이 안 통할 때**: 문서 협업이 핵심인 팀이에요. [ones.com의 2026년 비교 분석](https://ones.com/ko/blog/document-collaboration-tool-with-ai-6/)에 따르면 Slack Canvas는 버전 관리도 없고 폴더 구조도 얕아요. Google Docs + Gemini나 ONES.com처럼 요구사항·스프린트·지식 베이스가 네이티브로 연결된 도구와 비교하면 문서 관리 깊이가 떨어져요. 채팅 중심 업무엔 맞는데, 문서가 쌓이는 팀엔 안 맞아요.

**Slack Code가 무너질 때**: 지원 에이전트가 4개뿐이에요. 팀이 Cursor IDE나 다른 코딩 도구를 쓰고 있다면 Slack Code에 연결이 안 돼요. 대형 프로젝트의 컨텍스트 처리 능력도 각 에이전트 성능에 전적으로 의존해요. Slack 자체가 컨텍스트를 관리하는 게 아니라는 뜻이에요. 에이전트가 컨텍스트를 잘못 처리하면 Slack Code도 같이 무너지는 구조예요.

## 5. 최종 판정과 다음 단계

결론은 처음과 같아요. **비개발 팀이라면 Slack AI 기본 기능이 이겨요.** 채널 요약과 허들 노트는 회의 정리에 쓰는 시간을 실제로 줄여주고, Pro 플랜에 포함돼 있어요. 별도 구독 없이 바로 쓸 수 있다는 게 실질적인 이점이에요.

개발팀이라면 Slack Code는 Claude Code나 GitHub Copilot 구독이 이미 있을 때만 의미 있어요. PM과 디자이너를 코드 리뷰에 참여시키고 싶은 팀엔 진짜 유용한 기능이거든요.

**지금 바로 할 수 있는 한 가지:** Slack Pro 플랜 무료 체험으로 채널 요약 기능을 10분간 써보세요. 팀 채널에서 "지난 주 요약"을 실제로 돌려보면 값어치를 바로 판단할 수 있어요.

**지켜봐야 할 지점:** Slack Code의 지원 에이전트가 4개에서 10개 이상으로 늘어나는 시점이에요. OpenAI 연동 일정이 잡히는 순간 비개발 팀 적합도 평가가 달라질 수 있거든요.
