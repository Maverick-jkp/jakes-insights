앱 하나 만들고 싶어서 개발자한테 견적 물어봤다가 조용히 탭을 닫은 적 있죠? 근데 2026년 지금, 채팅창에 "점심 메뉴 추천해주는 앱 만들어줘"라고 치면 4분 만에 실제 돌아가는 앱이 나와요. 과장이 아니에요. [캐럿(Carrot) AI 미니앱 실사용 리뷰](https://m.news.nate.com/view/20260117n02881)에서 코딩 비전공자가 직접 테스트한 결과예요.

오늘은 세 개 플랫폼의 실사용 데이터를 뜯어볼게요.

> **핵심 요약**
> - 캐럿 AI 미니앱은 점심 메뉴 추천 앱을 최초 생성하는 데 약 4분, 오류 수정 후 재생성에는 14분까지 늘어나요.
> - Google AI Studio는 2분 내 앱 생성이 가능하지만, 한국어 텍스트 렌더링 오류와 API 쿼터 초과 같은 실질적 제약이 있어요.
> - 국내 개발자 Daniel Kim이 만든 '만들어줘 AI'는 대화 기반으로 실제 설치 가능한 APK 파일을 출력한다는 점에서 기술적으로 달라요.
> - 세 플랫폼 모두 간단한 유틸리티 앱 수준에서는 충분한 완성도를 보이지만, 복잡한 기능 구현에는 구체적인 프롬프트 설계 능력이 필요해요.

## 왜 지금 이 흐름인가

Bubble, Glide, Softr 같은 No-code 툴은 2020년대 초반부터 있었어요. 그런데 이 도구들은 UI 편집기를 배워야 했고, 로직을 블록으로 연결하는 법도 익혀야 했어요. "코딩은 없어도 러닝커브는 있다"는 역설이 있었던 거죠.

그 한계를 넘으려는 시도가 2025년 하반기부터 본격화됐어요. Vibe Coding이라는 개념 — 분위기를 설명하듯 대화로 개발하는 방식 — 이 등장하면서 AI가 코드 한 줄도 모르는 사람의 아이디어를 실제 동작하는 소프트웨어로 바꿔주기 시작했거든요.

[데일리팝 보도](http://www.dailypop.kr/news/articleView.html?idxno=104958)에 따르면, 딱 맞는 앱이 없어서 AI로 직접 만들어 쓰는 사람들이 실제로 늘고 있어요. 취미 기록 앱, 가계부 커스터마이징, 소규모 팀 업무 도구 — 앱스토어에 올리기엔 너무 사소하지만 본인에게는 꼭 필요한 것들이요.

개발자 한 명을 채용하거나 외주를 맡기면 최소 수백만 원이 드는 작업을 개인이 대화 몇 번으로 해결할 수 있다면, 이건 접근성의 문제예요. 기술 민주화라는 말이 드디어 실질적인 의미를 갖기 시작한 거죠.

## 실제 성능 데이터: 세 플랫폼 비교

### 캐럿 AI: 가장 풍부한 실사용 데이터

[캐럿 AI 미니앱 실사용 리뷰](https://m.news.nate.com/view/20260117n02881)는 세 플랫폼 중 가장 구체적인 숫자를 보여줘요.

점심 메뉴 추천 앱을 처음 만드는 데 **4분**. 오류가 생겨서 수정 후 재생성하니 **14분**. 두 번째 앱을 기획서 기반으로 만드니 **8분**에 버그 수정 배포까지 추가로 **4분**이 걸렸어요.

완성된 앱 구성이 꽤 인상적이에요. 홈·룰렛·퀴즈·통계·설정 5개 탭, 메뉴 주재료·가격·키워드 정보, 예산 통계 기능까지 포함됐거든요. 채팅 몇 번으로요.

다만 한계도 뚜렷해요:
- 초기 생성 시 날씨 기반 추천 기능 누락, UI 영문 표기, 이미지 오류 같은 버그가 많았어요
- 연속으로 수정 요청하면 알고리즘이 과부하로 응답을 멈추는 현상이 발생했어요
- 무료 플랜 사용량 한도 초과로 작업이 중단되기도 했죠

### Google AI Studio: 빠르지만 한국어가 약점

[Google AI Studio 실사용 기록](https://lilys.ai/ko/notes/google-ai-studio-20251202/ai-chat-builds-app-no-code)에 따르면 2분 내 앱 생성이 가능하고, 인테리어 디자인·이미지 변환·메뉴 추천·웹툰 제작까지 네 가지 앱 유형을 직접 구현해냈어요.

그런데 한국 사용자에게는 치명적인 문제가 있어요. Google Trends API가 한국 콘텐츠를 지원하지 않아서 직접 뉴스 기사를 넣어야 했고, AI가 생성한 이미지 안 한국어 텍스트가 깨져서 아예 텍스트 제거 프롬프트를 써야 했어요. 일일 API 쿼터 초과로 이미지 생성이 24시간 멈추는 일도 생겼죠.

### 만들어줘 AI: APK까지 출력하는 차별점

[Disquiet에 등록된 만들어줘 AI](https://disquiet.io/products/ai-a98ddb79-6db6-4d86-a27c-63c585ecc052)는 접근 방식이 달라요. 개발자 Daniel Kim이 개발 환경 세팅의 반복적인 번거로움을 없애려고 만든 앱인데, 대화로 코드를 생성하는 건 같아요. 차이는 결과물이에요.

다른 도구들이 웹 URL이나 UI 프리뷰를 주는 반면, 만들어줘 AI는 실제로 기기에 설치할 수 있는 **APK 파일**을 뽑아줘요. 포모도로 타이머, 계산기, 메모 앱을 개발자 본인이 직접 테스트하면서 만들었고, "버튼을 아래로 내려줘" 같은 자연어 명령으로 화면 레이아웃을 수정할 수도 있어요. 현재 무료로 Google Play에서 받을 수 있어요.

## 플랫폼별 비교

| 항목 | 만들어줘 AI | Google AI Studio | 캐럿 AI |
|------|------------|-----------------|---------|
| 생성 결과물 | APK (설치 파일) | 웹 앱 | URL 공유 가능 웹앱 |
| 최초 생성 속도 | 미공개 | 약 2분 | 약 4분 |
| 한국어 지원 | 네이티브 | 제한적 (텍스트 렌더링 오류) | 지원 |
| 무료 사용 | 무료 | 무료 (API 쿼터 제한) | 무료 플랜 (사용량 제한) |
| 멀티미디어 | 미지원 | 이미지 생성 포함 | 텍스트·이미지·영상·음악 |
| 주요 한계 | 초기 단계, 기능 미성숙 | 한국어 취약, 쿼터 제한 | 연속 수정 시 과부하 |
| 적합한 용도 | Android 네이티브 앱 | 멀티미디어 기반 앱 | 복합 기능 미니앱 |

세 플랫폼을 놓고 보면 패턴이 보여요. **빠른 프로토타입**이 목표라면 Google AI Studio가 2분이라는 속도로 앞서요. **한국어 환경에서 안정적인 기능**이 필요하다면 캐럿 AI가 낫고, **실제 Android 기기에 깔리는 앱**이 필요하다면 만들어줘 AI가 유일한 선택지예요.

참고로 세 도구 모두 "채팅 한 번으로 완성"은 아니에요. 초기 생성 후 버그 수정과 반복 프롬프트가 필요해요. 프롬프트를 얼마나 구체적으로 쓰느냐가 결과물의 완성도를 결정하는 핵심 변수예요.

## 실제로 쓸 사람들을 위한 현실적인 조언

**지금 당장 쓸 수 있는 사람:**
개인 생산성 도구, 소규모 팀 내부용 앱, 프로토타입 검증이 목적이라면 지금 시도해볼 만해요. 캐럿 AI 리뷰에서 나온 5탭 메뉴 앱처럼, 아이디어를 빠르게 형태로 만들어보는 용도로는 충분해요.

**프롬프트 작성 팁 세 가지:**
- 기능을 나열하지 말고 시나리오로 설명하세요. "날씨에 따라 메뉴를 추천해줘"보다 "비 오는 날 국물 요리를, 맑은 날엔 샐러드를 추천하는 앱"이 더 잘 돼요.
- 한 번에 모든 기능을 넣으려 하면 과부하가 걸려요. 핵심 기능 하나부터 만들고 대화로 덧붙이는 방식이 안정적이에요.
- 오류가 생기면 "고쳐줘" 대신 어떤 화면에서 어떻게 오류가 나는지 구체적으로 설명하세요. 그래야 AI가 맥락을 잡아요.

**아직 기다려야 할 사람:**
외부 API 연동이 필요하거나, 사용자 로그인·결제 기능이 들어가야 한다면 아직 이 도구들로는 힘들어요. API 쿼터 초과, 한국어 텍스트 오류, 연속 수정 시 응답 중단 — 이런 한계들이 프로덕션 수준 서비스 개발에는 걸림돌이에요.

## 앞으로 6개월, 무엇을 봐야 할까

솔직한 결론은 이래요. "쓸 수 있다. 단, 완성까지는 대화가 여러 번 필요하다."

앞으로 6개월 안에 주시할 변화가 있어요:
- **무료 플랜 한도 조정**: 캐럿 AI처럼 사용량 제한이 걸리는 구조가 유료 전환 압박으로 바뀔 가능성이 있어요.
- **한국어 멀티모달 처리 개선**: Google AI Studio의 한국어 텍스트 렌더링 오류 같은 문제는 모델 업데이트로 빠르게 해결될 수 있어요.
- **APK 외 iOS 대응**: 만들어줘 AI가 현재 Android만 지원하는데, iOS 출력 지원 여부가 핵심 분기점이 될 거예요.

지금 머릿속에 "앱으로 만들면 좋겠는데"라고 생각만 하고 접어둔 아이디어가 있지 않나요? 4분이면 첫 화면을 볼 수 있어요. 꺼내볼 타이밍이 왔을 수도 있어요.
