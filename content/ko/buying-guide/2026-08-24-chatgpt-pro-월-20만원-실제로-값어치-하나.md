## Pro가 두 개라고요? 요금 구조부터 정리해요

2026년 8월 기준 OpenAI 한국 요금 페이지에는 개인 플랜 네 가지가 있어요. [AI 디코드 정리](https://the-maze.tistory.com/117)에 따르면 Go(월 1만 3천 원), Plus(월 2만 9천 원), Pro 5x(월 약 15만 9천 원), Pro 20x(월 약 29만 9천 원)예요. 참고로 KRW 결제는 달러 요금에 카드 환율과 부가세 10%를 곱해서 나와요. 1,400원/달러 기준으로 계산하면 Pro 20x는 약 30만 8천 원 수준이에요.

핵심은 Pro 5x와 Pro 20x의 기능 목록이 동일하다는 거예요. 차이는 딱 하나, **사용량**이에요.

| 구분 | 포함 내용 |
|------|-----------|
| Go | GPT-5.6 Instant + 이미지 생성, 광고 포함, 컨텍스트 54K |
| Plus | 고급 추론 모델 + Codex + 딥리서치 + Work 전체 접근, 컨텍스트 256K |
| Pro 5x | Plus 사용량 5배 + Frontier Pro 모델 + 코덱스 최대화, 컨텍스트 400K |
| Pro 20x | Pro 5x 동일 기능 + 사용량 20배 + 코덱스 풀 에이전트 + 워크 에이전트 |

컨텍스트 창 차이도 상당해요. [AI 디코드](https://the-maze.tistory.com/117)가 정리한 표를 보면 Plus의 추론 모델 컨텍스트는 약 256K(320페이지 분량), Pro는 400K(680페이지 분량)예요. 법률 문서 검토나 긴 코드베이스 분석처럼 맥락이 길어야 하는 작업에선 이 차이가 바로 느껴지죠.

## ChatGPT Pro vs Claude Code: 코딩 에이전트 비교

Pro 20x를 쓰는 가장 큰 이유 중 하나예요. [AI Solutions 분석](https://aisolutions.kr/2026/07/23/chatgpt_pro_20x_payment_reason_codex_coding_better_than_claude_code/)에 따르면 Codex와 Claude Code의 구조적 차이가 분명해요.

**ChatGPT Codex (Pro 20x 포함):**
- **장점**:
  - 메인 대화 스레드와 별개로 백그라운드 에이전트 병렬 실행
  - 사용량 리셋이 없어 장시간 세션에서 중단 없이 작업 가능
  - 추론 강도 5단계 (Light → Ultra) 선택으로 쿼터 관리 가능
  - 워크 에이전트로 코딩 이외 업무 자동화까지 확장
- **단점**:
  - Ultra 모드 사용 시 쿼터 소모가 매우 빠름
  - Pro 5x는 헤비 유저 기준 하루 안에 한계 도달
- **최적 용도**: 긴 코드베이스 작업, 병렬 태스크, 에이전트 자동화

**Claude Code MAX 20x:**
- **장점**:
  - 코딩 품질 자체는 여전히 강력
  - 단순 태스크 완성도 높음
- **단점**:
  - 5시간마다 사용량 리셋되는 구조
  - 실제 보고된 사용 패턴: 하루 실사용이 22% 수준에 그침
  - USD 결제에 VAT 10% 추가로 한국 사용자 실부담 더 높음
- **최적 용도**: 짧고 집중적인 스프린트 코딩

두 서비스를 동시에 구독하는 사람들도 있어요. 한쪽이 리셋되는 동안 다른 쪽을 쓰는 방식으로요. 그런데 [AI Solutions](https://aisolutions.kr/2026/07/23/chatgpt_pro_20x_payment_reason_codex_coding_better_than_claude_code/)에 따르면 동시 구독 시 월 50만 원을 넘어요. 비용 대비 효과를 따지면 단일 서비스 최적화가 먼저예요.

병렬 에이전트 구조의 실질적 차이를 하나만 들면 이거예요. 메인 대화를 하면서 백그라운드에서 다른 에이전트가 코드를 짜고 있다면, 같은 시간에 두 배 이상의 작업이 가능해요. Claude Code는 구조 자체가 이 방식을 허용하지 않아요.

## 누구한테 Pro가 맞고, 누구한테 Plus로 충분한가

[emotionte 가격 비교](https://emotionte.com/%EC%B1%97gpt-%EC%9C%A0%EB%A3%8C-%EA%B0%80%EA%B2%A9-%EC%B4%9D%EC%A0%95%EB%A6%AC-%EC%B5%9C%EC%8B%A0-%EC%9A%94%EA%B8%88%EC%A0%9C-%EA%B8%B0%EB%8A%A5-%EB%B9%84%EA%B5%90/)에서는 Pro 전환 기준을 이렇게 제시해요. "Plus 대비 월 18만 원 비용 차이를 뛰어넘는 생산성 향상이 있을 때만 Pro가 답이다."

**Plus로 충분한 경우:**
- 하루 ChatGPT 사용 시간이 2~3시간 이하
- 문서 작성, 이미지 분석, 딥리서치가 주 업무
- 코딩은 하지만 짧은 세션 위주
- 에이전트 자동화 없이 대화형으로 주로 사용

**Pro 5x가 맞는 경우:**
- 하루 종일 ChatGPT를 켜놓고 일함
- 추론 모드(High 이상)를 자주 씀
- 가끔 Codex로 코딩하지만 쿼터가 자주 막힘

**Pro 20x가 맞는 경우:**
- Pro 5x 한계를 하루 안에 소진하는 패턴이 반복됨
- 병렬 코딩 에이전트가 실제 업무 흐름에 필요함
- 워크 에이전트로 반복 작업 자동화를 실제로 쓰고 있음

[AI Solutions](https://aisolutions.kr/2026/07/23/chatgpt_pro_20x_payment_reason_codex_coding_better_than_claude_code/)이 권장하는 경로는 단순해요. Pro 5x부터 시작하고, 쿼터 소진이 잦아지면 20x로 올리세요. 처음부터 20x를 지를 이유는 대부분 없어요.

추론 강도 5단계도 쿼터 관리에 중요해요. Ultra 모드는 쿼터를 훨씬 빠르게 먹어요. 복잡한 작업이 아닌 경우 Light나 Medium으로 쓰면 같은 쿼터로 훨씬 오래 쓸 수 있거든요.

## 결론: 30만 원짜리 구독, 어떻게 판단하나요

**정리하면 이래요:**

- ChatGPT Pro 20x는 가격이 비싸지만 기능 자체는 명확해요 — 사용량 20배와 병렬 코딩 에이전트
- Claude Code와의 구조적 차이(5시간 리셋 vs. 상시 병렬)가 헤비 코더한테는 의미 있는 차이예요
- 일반 업무 사용자에게 Plus(월 2만 9천 원)는 여전히 가성비 1위예요
- Pro는 "비싼 구독을 정당화할 업무 강도"가 먼저예요

앞으로 6개월 안에 OpenAI가 워크 에이전트 기능을 더 확장하면, Pro의 가치는 코딩 이외 영역에서도 올라갈 거예요. 에이전트가 단순 보조 역할을 넘어서 반복 업무 전체를 맡기 시작하면요. 그 시점에 Plus와 Pro의 격차는 지금보다 더 벌어질 수 있어요.

지금 당장 판단 기준은 하나예요. **지난 한 달 동안 쿼터에 막혀서 일이 멈춘 적이 몇 번이었나요?** 두 번 이상이면 Pro 5x를, 매일이면 Pro 20x를 고려해볼 만해요.
