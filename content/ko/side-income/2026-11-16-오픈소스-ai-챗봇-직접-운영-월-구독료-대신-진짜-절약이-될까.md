매달 ChatGPT Plus에 2만 9천 원, Claude Pro에 2만 원. API까지 쓰면 50만 원이 훌쩍 넘는다는 얘기도 심심찮게 들려요. 그러다 보니 요즘 "그냥 내 컴퓨터에서 돌리면 안 되나?" 하고 오픈소스 AI 챗봇 직접 운영을 고민하는 사람들이 빠르게 늘고 있어요. 근데 진짜로 쌀까요? 아니면 숨겨진 비용이 더 클까요?

> **핵심 요약**
> - 2026년 현재 Ollama + Open WebUI 조합으로 로컬 AI 챗봇을 구축하면 월 구독료 0원이 가능하지만, 초기 하드웨어 투자와 운영 난이도라는 현실적인 비용이 존재한다.
> - Brunch 사례에 따르면 중간 규모 챗봇의 API 비용이 월 50만 원을 초과하는 경우, 로컬 운영 전환 시 1년 이내 손익분기점 도달이 현실적이다.
> - CPU만으로는 14B 모델 기준 초당 2~5토큰 수준에 그치고, RTX 3060 GPU를 갖춰야 초당 20~30토큰으로 체감 품질이 달라진다.
> - 개인 사용자라면 Ollama + Qwen3 8B 조합이 가장 진입 장벽이 낮고, 팀 단위라면 Proxmox + Open WebUI 서버 스택이 더 현실적이다.

## 왜 지금 이 질문인가

AI 구독료 부담은 2026년 들어 본격적인 이슈가 됐어요. 개인은 한 달에 여러 서비스를 쓰다 보면 5만~10만 원이 훌쩍 넘고, 소규모 스타트업이나 1인 개발자는 API 비용이 매달 수십만 원씩 나와요. 한국경제 보도에 따르면 ChatGPT API의 토큰 요금제 구조상, 문서 요약이나 챗봇 서비스를 운영할 경우 월 100만 토큰 소비는 금방 현실이 된다고 해요.

반면 오픈소스 진영은 빠르게 성숙했어요. Llama 3.1, Qwen2.5, DeepSeek-R1 같은 모델들이 등장하면서 "무료로 돌릴 수 있는 모델"의 품질이 1~2년 전과 완전히 달라졌거든요. 여기에 Ollama가 Docker처럼 모델을 패키지 단위로 관리해주는 구조를 만들면서 설치 허들도 크게 낮아졌고요.

오픈소스 AI 챗봇 직접 운영이라는 선택지가 "긱들의 취미"에서 "진지한 비용 절감 방법"으로 올라온 게 바로 2026년의 맥락이에요.

## 실제로 얼마나 드나: 비용 구조 해부

### 로컬 운영의 초기 투자

오해가 있어요. 오픈소스라고 비용이 0원은 아니에요. 하드웨어 요건이 있거든요.

실질적인 최소 사양은 아래와 같아요:

| 구분 | 최소 사양 | 권장 사양 |
|------|-----------|-----------|
| RAM | 8GB (7B 모델 한정) | 16GB 이상 |
| 저장공간 | 100GB SSD | 256GB SSD 이상 |
| GPU | 없어도 가능 (느림) | RTX 3060 12GB VRAM |
| 성능 (14B 모델) | 2~5 tokens/sec | 20~30 tokens/sec |

현실적인 얘기를 해볼게요. CPU만으로 돌리면 초당 2~5토큰이에요. 한 문장 나오는 데 5~10초 걸린다는 얘기죠. 실용적으로 쓰기 어려워요. RTX 3060 GPU가 있으면 초당 20~30토큰으로 올라가서 ChatGPT와 체감상 비슷해져요. 이미 GPU가 있다면 이야기가 다르지만, 새로 사면 50만~100만 원 추가 비용이 생기는 셈이에요.

### 클라우드 API vs. 로컬 운영: 손익분기점

월 API 비용이 50만 원이라면, 로컬 서버 구축에 초기 100만~150만 원을 써도 2~3개월이면 본전이에요. GPU 없이 서버용 중고 PC로 구성하면 30만~50만 원 선에서도 가능하고요.

반면 개인 사용자가 월 2만 9천 원짜리 ChatGPT Plus를 대체하려고 50만 원짜리 GPU를 산다면? 손익분기점이 17개월 뒤예요. 사용 빈도와 목적에 따라 계산이 완전히 달라지는 거죠.

## 세 가지 셋업 옵션 비교

**Option A: Ollama + 터미널 (가장 간단)**
- **장점**: 설치 2분, 명령어 두 개로 끝 (`ollama pull qwen3:8b` → `ollama run qwen3:8b`), 무료
- **단점**: 대화창이 없음, 여러 명이 쓰기 어려움
- **이런 분께**: 개발자, CLI 익숙한 개인 사용자

**Option B: Ollama + Open WebUI (실용적 중간점)**
- **장점**: ChatGPT와 비슷한 웹 인터페이스, 2026년 3월 기준 GitHub 별 9만 개 돌파, RAG·이미지 생성·웹 검색 지원
- **단점**: 설치 과정 약간 복잡, 로컬에서 `http://localhost:8080` 접속
- **이런 분께**: 혼자 쓰거나 소수 팀, 프라이버시가 중요한 케이스

**Option C: Proxmox + Ollama + Open WebUI (팀/서버용)**
- **장점**: 여러 사람이 동시에 사용 가능, GPU를 여러 컨테이너가 나눠 쓸 수 있음, 24시간 운영
- **단점**: 하이퍼바이저 설정 필요, 초기 세팅 난이도 높음
- **이런 분께**: 팀 단위, 사내 AI 서버 구축

참고로 Proxmox는 VMware가 Broadcom에 인수된 뒤 라이선스 정책이 불안정해지면서 홈랩의 사실상 표준이 됐어요. LXC 컨테이너 방식을 쓰면 VM보다 메모리 오버헤드가 훨씬 작고, GPU를 여러 컨테이너가 동시에 나눠 쓸 수 있다는 점도 장점이에요.

## 어떤 모델을 써야 할까

모델 선택이 체감 품질을 결정해요. Qwen3 8B는 다운로드 크기 약 5.2GB, 한국어 성능이 뛰어나고 `<think>` 태그로 추론 과정이 보여서 디버깅에도 좋아요. Alibaba가 만든 모델이라는 점이 걸리는 분들도 있겠지만, 오프라인으로만 쓰면 데이터 유출 우려는 없어요.

**2026년 현재 추천 모델 조합**:
- 일반 대화: Llama 3.1 8B 또는 Qwen2.5 14B
- 코딩: Qwen2.5-Coder 7B
- 한국어 특화: DeepSeek-R1 8B

코딩 어시스턴트로는 `Continue`도 주목할 만해요. VS Code와 JetBrains에 붙는 오픈소스 플러그인인데, GitHub Copilot 대신 쓸 수 있고 로컬 모델에 연결하면 월 구독료 없이 코드 자동완성이 가능해요.

## 누가 쓰면 진짜 절약이 되고, 누가 쓰면 아닌가

### 로컬 운영이 맞는 경우

- **월 API 비용이 10만 원 이상**인 1인 개발자나 소규모 서비스 운영자
- **데이터 프라이버시**가 핵심인 의료, 법률, 금융 관련 업무
- **고용량 문서 처리**가 반복적인 케이스 (계약서 요약, 회의록 전사 등)
- 이미 **쓸 만한 GPU가 집에 있는** 개발자

Whisper를 활용하면 인터뷰·회의 녹음도 로컬에서 텍스트로 바꿀 수 있어요. 한 시간 분량 오디오를 외부 서버에 올리지 않아도 된다는 점에서 프라이버시 측면의 가치가 커요.

### 그래도 유료 구독이 나은 경우

- 멀티모달(이미지 분석, 실시간 음성 등) 기능이 필수인 경우
- 최신 모델의 최고 성능이 필요한 경우
- 빠르게 테스트하고 결과를 내야 하는 프로토타이핑
- IT 환경 설정에 시간 쓰기 싫은 경우

Vinod Khosla가 지적한 것처럼, 오픈소스 모델은 "공짜로 쓸 수 있다"와 "실제로 더 싸다"는 다른 얘기예요. 하드웨어 감가상각, 전기료, 설정·유지 시간을 비용으로 환산하면 생각보다 차이가 줄어드는 경우도 있거든요.

## 결론: 계산기를 꺼내야 할 타이밍

"케이스마다 달라요"가 아니라 "계산하면 나와요"예요.

월 API 비용이 10만 원 넘으면 1년 안에 본전 나와요. 개인 ChatGPT Plus 대체용이면 GPU 살 돈으로 2년 치 구독료가 나오는 셈이기도 하고요. 지금 당장 해볼 수 있는 첫 단계는 간단해요. Ollama 설치하고 Qwen3 8B 모델 받아서 사흘만 써보세요. 그것만으로도 로컬 AI가 내 워크플로우에 맞는지 감이 잡혀요.

그 다음 질문은 하나예요. "지금 쓰는 AI 도구에 한 달에 얼마 쓰고 있나요?"
