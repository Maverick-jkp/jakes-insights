코딩 한 줄 몰라도 나흘 만에 3D 게임을 만들었다는 얘기, 들어보셨나요?

과장이 아니에요. [서울경제 보도](https://m.sedaily.com/article/20114263)에 따르면 2026년 현재 AI 도구로 비개발자가 완성도 있는 게임을 제작한 사례가 국내외 커뮤니티에서 빠르게 늘고 있어요. 그런데 여기서 질문 하나. 이게 진짜 "게임 만들기"일까요, 아니면 그냥 그럴싸해 보이는 뭔가를 뚝딱 만든 걸까요?

데이터로 직접 답해볼게요.

> **핵심 요약**
> - GPT-6 Astra와 Codex CLI 조합으로 비개발자가 2~4시간 안에 플레이 가능한 HTML5 게임을 완성한 사례가 2026년 9~10월 사이 Reddit, itch.io 등 해외 커뮤니티에서 반복 보고됐어요.
> - OpenAI GPT-4o의 "Intelligent UI" 기능은 별도 개발 환경 없이 대화창 안에서 아케이드 게임 5종을 구현하는 데 성공했고, Tetris가 가장 안정적인 결과물을 보였어요.
> - 단, $100 구독 기준 게임 데모 2개를 만드는 데 약 4시간 만에 주간 사용량 한도가 소진됐고, 완성도 있는 게임엔 수백~수천 달러 비용이 발생할 수 있어요.
> - "게임처럼 보이는 결과물"과 "실제 플레이 가능한 게임"은 여전히 별개의 단계예요 — 이 차이를 이해하는 게 현실적 접근의 출발점이에요.

## 무슨 일이 벌어지고 있나: 2026년 AI 게임 개발의 맥락

불과 2년 전만 해도 Unity를 배우는 데만 수개월이 걸렸어요. C# 문법, 셰이더, 물리 엔진 — 이걸 다 익혀야 비로소 "게임다운 게임"을 만들 수 있었죠.

2026년 9월, OpenAI가 GPT-6 Astra를 공개하면서 흐름이 달라졌어요. 같은 달 Reddit에서는 Godot과 Blender MCP를 연동해 반나절 만에 포스트 아포칼립스 3D 장면을 구현한 사례가 올라왔어요. [YouTube 채널 AI Builders Lab 보도](https://note.com/ai_builders_lab/n/n7a16364d5352?hl=en)에 따르면 10월 24일에는 개발 경험이 전혀 없는 Hakimi Eiqbal이 Godot과 Hyper3D Rodin 조합으로 3일 만에 모바일 드라이빙 게임을 완성했어요.

핵심 도구는 세 가지예요.

- **ChatGPT (GPT-5.5 / GPT-6 Astra)**: 게임 기획, 메커니즘 설계, 명세 문서 작성
- **OpenAI Codex CLI**: `npm install -g @openai/codex` 명령어로 설치, 멀티파일 코드 생성
- **브라우저 + VS Code**: 무료로 테스트 환경 구성 가능

이 조합이 처음으로 "무료 티어 안에서 완결된 첫 게임 제작"을 가능하게 만들었기 때문이에요. 초기 프로젝트 기준 비용 제로가 현실이 된 거죠.

## 실제로 뭘 만들 수 있나: 세 가지 현실 시나리오

### 대화창 안에서 바로: GPT-4o Intelligent UI

[디지털투데이 테스트 결과](https://www.digitaltoday.co.kr/news/articleView.html?idxno=709212)가 흥미로워요. GPT-4o의 Intelligent UI 기능으로 대화창 안에서 클래식 아케이드 게임 다섯 종을 직접 만들어봤는데 결과는 이랬어요.

- **Snake**: 속도 조절 기능 포함 재현 성공. 사이버펑크 변형 버전도 구현
- **Tetris**: 가장 안정적. 회전 보드, 특수 블록 변형까지 소화
- **Space Invaders**: 라운드 간 외계인과 협상할지 전투할지 선택하는 분기점 추가 — 플레이 난이도가 동적으로 바뀌는 구조로 구현
- **Pac-Man**: 비밀 통로, 추가 적 캐릭터 포함한 변형판 완성
- **Pong**: 점수마다 무작위 규칙 변경(공 분열, 패들 축소, 중력 변화) 버전 성공

단, 복잡한 규칙 수정 요청은 정확도가 떨어졌고, 같은 프롬프트를 반복해도 결과가 일관되지 않았어요. 처음에 플레이 화면 대신 코드만 출력되는 경우도 있었어요.

### Codex CLI로 본격 HTML5 게임 개발

[AI Builders Lab 가이드](https://note.com/ai_builders_lab/n/n7a16364d5352?hl=en)가 제시한 워크플로우는 이래요. ChatGPT로 30분간 명세 문서 만들기 → Codex CLI로 코드 생성(index.html, style.css, game.js) → Chrome DevTools 오류를 Codex에 직접 붙여넣어 디버깅 → 2~3번 반복.

단순한 HTML5/Canvas 게임은 한 번 생성에 작동 상태까지 가는 경우도 있어요. 총 소요 시간: 2~4시간.

### 3D 게임: 가능하지만 조건이 붙어요

Godot + Hyper3D Rodin + GPT-6 Astra 조합으로 3D 게임 제작이 가능해졌어요. 그런데 커뮤니티에서 올라온 비판 하나가 현실을 정확히 짚어줘요. "3D 게임이 아니라 3D 장면에 가깝다"는 댓글이 달렸거든요. 실제로 움직이고 상호작용하는 게임과, 그럴싸해 보이는 렌더링 결과물 사이에는 아직 간극이 있어요.

## 비용 vs 접근성: 두 가지 경로 비교

| 항목 | ChatGPT Intelligent UI | Codex CLI + ChatGPT |
|------|------------------------|---------------------|
| 초기 비용 | 무료 (GPT-4o 기본 제공) | 무료 (Node.js 설치 필요) |
| 개발 환경 설정 | 불필요 | VS Code + npm 설치 |
| 완성 가능한 게임 복잡도 | 2D 아케이드 중심 | 2D~간단한 3D |
| 첫 결과물까지 소요 시간 | 10~30분 | 2~4시간 |
| 고사양 프로젝트 비용 | 주간 한도 빠르게 소진 | 수백~수천 달러 가능 |
| 배포 옵션 | 대화창 내 플레이 | itch.io, Netlify, GitHub Pages |
| 비개발자 접근성 | 매우 높음 | 보통 (CLI 기초 필요) |
| AI 버그 수정 신뢰도 | 중간 | 중간 (직접 검증 필수) |

비용 현실은 직시해야 해요. Reddit 보고에 따르면 $100 구독 기준으로 게임 데모 두 개를 만드는 데 약 4시간 만에 주간 사용량 한도가 소진됐어요. 완성도 높은 게임을 만들려면 수백에서 수천 달러가 필요할 수 있다는 얘기죠.

무료로 첫 게임을 만들어보는 건 가능해요. 그걸 상업적으로 쓸 만한 수준으로 다듬는 건 다른 얘기예요.

## 비개발자가 알아야 할 세 가지 현실

### "완성"의 기준을 먼저 정해야 해요

이 질문의 답은 "완성"을 어떻게 정의하느냐에 달려 있어요.

- 친구들과 대화창에서 같이 해보는 미니게임? **가능해요.**
- itch.io에 올려서 피드백 받는 프로토타입? **2~4시간이면 가능해요.**
- App Store에 올릴 모바일 게임? **아직 별도 역량이 필요해요.**

MVP 수준의 웹서비스나 게임 데모는 AI로 충분히 만들 수 있어요. 그런데 보안, 결제, 서버 확장성 — 이건 AI가 대신해주지 않아요.

### AI가 "완료"라고 해도 직접 테스트하세요

[letspl.me 분석](https://letspl.me/quest/2429/%EA%B0%9C%EB%B0%9C%EC%9E%90%20%EC%97%86%EC%9D%B4%20%EA%B2%8C%EC%9E%84%EA%B3%BC%20%EC%9B%B9%EC%84%9C%EB%B9%84%EC%8A%A4%EB%A5%BC%20%EB%A7%8C%EB%93%A4%20%EC%88%98%20%EC%9E%88%EC%9D%84%EA%B9%8C%20GPT6%20Astra%EC%9D%98%20%EA%B0%80%EB%8A%A5%EC%84%B1%EA%B3%BC%20%ED%95%9C%EA%B3%84)에서 커뮤니티가 공유한 원칙이 정확해요. AI가 버그 수정 완료를 보고해도 실제로는 미해결인 경우가 반복 보고됐거든요. 세 가지 원칙이에요.

1. 코드 구조는 최대한 단순하게 유지하기
2. 변경사항은 하나씩 테스트하기
3. AI 수정 결과를 무조건 직접 실행해서 확인하기

### 도구 선택: 목적에 따라 갈려요

빠르게 아이디어를 검증하고 싶다면 ChatGPT Intelligent UI가 맞아요. 10분 안에 뭔가가 화면에 나오거든요. 조금 더 완성도 있는 결과물을 원한다면 Codex CLI와 Phaser 3, p5.js 같은 프레임워크를 써보세요. Kenney.nl이나 OpenGameArt에서 무료 에셋도 가져올 수 있어요. 배포는 itch.io나 GitHub Pages로 무료로 가능하고요.

## 앞으로 6~12개월, 뭘 주시해야 할까요

지금 흐름을 보면 몇 가지 방향이 보여요.

**단기 (내년 상반기까지)**: 멀티파일 코드 생성 품질이 올라가면서 2D 게임의 완성도가 높아질 가능성이 커요. Codex CLI의 자동 디버깅 루프가 개선되면 비개발자의 첫 게임 완성 시간이 1~2시간 아래로 내려올 수 있어요.

**중기 (1년 이내)**: 3D 게임 제작에서 "장면"과 "실제 게임" 사이의 간극이 얼마나 좁혀지는지가 핵심 변수예요. Godot + AI 조합이 진짜 플레이 가능한 3D 게임을 비개발자 손에서 나오게 만든다면, 인디 게임 시장의 구조 자체가 달라지거든요.

**지켜봐야 할 신호**: OpenAI가 Codex의 비용 모델을 어떻게 바꾸는지예요. 지금은 무료 티어가 있지만, 사용량 한도가 엄격해질수록 비개발자의 접근성이 다시 좁아질 수 있어요.

자, 결론이에요. 2026년 기준으로 "간단한 수준에서는 가능하고, 완성도를 높일수록 추가 비용과 역량이 필요하다"는 공식이 성립해요. 도구는 충분히 발전했어요. 이제 질문은 "만들 수 있나"가 아니라 "무엇을 얼마나 만들 건가"예요.

만들고 싶은 게임이 있다면, 오늘 ChatGPT 대화창에서 Snake 하나 먼저 만들어보세요. 그게 가장 빠른 답이에요.
