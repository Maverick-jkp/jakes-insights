매달 $20씩 나가는 ChatGPT Plus 구독료. 연간으로 치면 24만 원이에요. 그런데 지금 맥북 사용자 30만 명 이상이 이 돈을 안 내고 AI를 쓰고 있어요.

애플 실리콘 칩의 통합 메모리 구조 덕분이에요. M1 이후 맥북은 GPU와 CPU가 같은 메모리를 공유하는데, 이게 AI 모델을 로컬에서 돌리기에 딱 맞는 구조예요. 클라우드 서버 없이, 내 맥북 안에서 AI가 직접 작동하는 시대가 된 거죠.

"근데 정말 ChatGPT 대체가 되냐"는 질문이 남아요. 데이터로 따져볼게요.

> - LM Studio, Ollama, GPT4All 등 앱마다 성격이 달라서 용도에 따라 골라 쓰는 게 맞아요.
> - 구독료 없이 ChatGPT를 완전히 대체하려면 RAM 용량이 핵심 변수예요.

## 왜 지금 로컬 AI가 뜨고 있나

2023년까지만 해도 "AI를 내 컴퓨터에서 돌린다"는 건 리눅스 터미널에 익숙한 개발자들 얘기였어요. 모델 크기가 수십 GB에 달했고, 설정만 하다가 하루가 갔죠.

2026년엔 두 가지가 완전히 달라졌어요.

첫 번째는 **모델 경량화**예요. Meta의 Llama 3, 알리바바의 Qwen 3, 마이크로소프트의 Phi-4 Mini 같은 모델들은 2~5GB 용량으로 실용적인 성능을 내요. 예전에 70B 모델이 필요했던 작업을 이제 8B 모델이 처리해요.

두 번째는 **애플 실리콘의 메모리 구조**예요. [refurb.me 가이드](https://www.refurb.me/blog/run-local-ai-on-mac)에 따르면, AI 추론 속도에서 칩 세대보다 메모리 대역폭이 더 중요해요. M3 Max의 메모리 대역폭은 초당 400GB인데, M4 기본형은 120GB예요. 같은 M4 시리즈라도 Max가 대형 모델에서 압도적으로 빠른 이유죠.

법률, 의료, 금융처럼 데이터를 외부 서버에 보내면 안 되는 업종에서 특히 관심이 커요. 프롬프트 자체가 기밀인 경우가 많아서요. 로컬 AI는 데이터가 기기 밖으로 나가지 않는다는 점에서 실질적인 수요가 생기고 있어요.

## 실제 성능은 어느 정도인가

### 속도: 언제부터 "답답하지 않냐"

AI 응답 속도는 초당 토큰 수(tokens/second)로 측정해요. 화면에 텍스트가 흘러나오는 속도예요.

[refurb.me 가이드](https://www.refurb.me/blog/run-local-ai-on-mac)의 벤치마크를 보면:

- **M4 Max 64GB + Qwen 3 8B (MLX)**: 초당 95~110 토큰
- **M4 Pro 48GB + Qwen 3 32B (MLX)**: 초당 12~22 토큰
- **M2 Ultra 192GB + Qwen3 235B (MLX)**: 초당 약 30 토큰

실사용 기준으로는 초당 10 토큰 이상이면 대화가 자연스러워요. 5 토큰 이하면 확실히 버벅이는 느낌이에요. M4 Pro 이상에서 8B 모델을 쓰면 ChatGPT랑 체감 속도 차이가 거의 없어요.

### RAM별 쓸 수 있는 모델

| RAM 용량 | 실행 가능 모델 크기 | 대표 모델 | 체감 품질 |
|----------|------------------|-----------|---------|
| 8 GB | 최대 3B | Llama 3.2 3B | 간단한 Q&A 수준 |
| 16 GB | 7B~8B | Qwen 3 8B Q4 | 실무 일반 용도 |
| 24~48 GB | 14B~32B | Qwen 2.5 Coder 32B | GPT-4급 근접 |
| 64 GB 이상 | 70B 이상 | DeepSeek 등 | 프런티어 모델급 |

16GB가 사실상 실용 최저선이에요. 8GB 맥북에어로 돌리는 3B 모델은 문서 요약 정도는 되지만, 복잡한 추론이나 코드 작성엔 무리가 있어요.

### 앱 비교: 뭘 써야 하나

[promptquorum.com 가이드](https://www.promptquorum.com/ko/power-local-llm/local-ai-app-non-technical-users)에서 분석한 주요 앱을 정리하면:

| 앱 | 설치 난이도 | 속도 (M3 Pro 16GB, 8B 기준) | 특징 | 라이선스 |
|---|-----------|--------------------------|-----|--------|
| **LM Studio** | 쉬움 | 35~42 tok/s | 허깅페이스 5,000개 모델 탐색, Metal 최적화 | 무료 (사유) |
| **GPT4All** | 매우 쉬움 | 8~15 tok/s | 290MB 설치, 4번 클릭으로 시작 | MIT |
| **Jan** | 쉬움 | 보통 | 텔레메트리 기본 꺼짐, 보안 중심 | AGPL |
| **Msty** | 쉬움 | 보통 | 모델 나란히 비교, PDF 대화 | 무료 (사유) |
| **Ollama** | 중간 | 좋음 | API 제공, 개발자 친화적 | MIT |
| **Atomic Chat** | 쉬움 | 보통 | iOS/Android 동시 지원 | Apache 2.0 |

처음 로컬 AI를 써보는 사람이라면 LM Studio가 가장 무난해요. 터미널 없이 앱처럼 쓸 수 있고, 애플 실리콘에서 Metal 커널을 써서 속도도 빠르거든요. 개발자라면 Ollama가 나아요. OpenAI API 형식으로 기존 코드와 바로 연결이 돼요.

## 구독료 없이 ChatGPT를 대체할 수 있나 — 솔직한 평가

### 로컬 AI가 앞서는 영역

- **개인정보 보호**: 프롬프트가 외부 서버에 전혀 안 가요. 법무팀 문서나 환자 기록을 다루는 경우엔 이게 결정적이에요.
- **비용**: 초기 셋업만 하면 이후 비용 제로예요. ChatGPT Plus $20/월, Claude Pro $20/월과 비교하면 1년이면 큰 차이가 나죠.
- **오프라인**: 인터넷 없이도 작동해요. 기내나 보안망 환경에서도 쓸 수 있어요.
- **맞춤화**: [overchat.ai](https://overchat.ai/local-ai)에 따르면, Atomic Chat은 세션 간 메모리를 유지해서 "TypeScript와 Tailwind CSS 쓴다"고 한 번만 말하면 다음부터 자동으로 적용돼요.

### ChatGPT가 여전히 앞서는 영역

- **최신 정보**: 로컬 모델은 학습 데이터 컷오프 이후 정보가 없어요. 웹 검색 없이는 최신 뉴스나 트렌드를 물어봐도 답이 어긋나요.
- **멀티모달**: ChatGPT의 이미지 생성, 파일 분석, 음성 대화는 로컬 환경에서 구현하기 복잡해요.
- **대형 모델 품질**: GPT-4o급 성능을 내려면 32B 이상 모델이 필요하고, 최소 48GB RAM 맥북이 있어야 해요. 16GB 맥북에서 8B 모델은 GPT-4o보다 확실히 아래예요.

## 어떻게 시작할까 — 용도별 권장 경로

**개인 생산성 / 처음 시작하는 경우**

LM Studio 설치 → Qwen 3 8B Q4 모델 다운로드(약 5GB) → 16GB RAM 이상이면 바로 시작. 설치부터 첫 대화까지 15분 안에 끝나요.

**코딩 보조가 주목적인 경우**

Ollama 설치 후 Qwen 2.5 Coder 32B를 받아서 VS Code 익스텐션과 연결하세요. 48GB RAM이 필요하지만, GitHub Copilot $19/월을 없앨 수 있어요.

**보안/프라이버시가 최우선인 경우**

Jan 앱을 쓰세요. 기본적으로 텔레메트리가 꺼져 있고, 소스코드를 직접 감사할 수 있어요. 시작 모델은 Phi-4 Mini(약 2.6GB)로 가볍게 시작하세요.

**다음 6~12개월에 볼 것들**

M5 칩이 탑재된 맥북에어의 최대 RAM이 32GB로 올라갔어요. 이전 세대보다 모델 선택지가 넓어진 거예요. 애플의 MLX 프레임워크도 계속 업데이트되고 있어서, 같은 하드웨어에서 내년엔 지금보다 20~30% 더 빠른 추론 속도가 나올 가능성이 높아요.

## 결론

맥북에서 로컬 AI 쓰는 법은 2026년에 이미 기술자의 전유물이 아니에요. LM Studio 하나 깔고 모델 하나 내려받으면 15분 만에 시작할 수 있어요.

구독료 없이 ChatGPT를 대체할 수 있냐는 질문엔 조건부 "예스"예요. 16GB RAM 이상 맥북이 있고, 최신 정보 검색보다 글쓰기·코딩·문서 분석이 주된 용도라면 대체가 돼요. 반대로 8GB 맥북에서 GPT-4o를 기대한다면 실망할 수밖에 없어요.

가장 현실적인 접근은 이거예요. 로컬 AI로 일상 작업 70~80%를 처리하고, 최신 정보나 복잡한 추론이 필요할 때만 ChatGPT를 쓰는 하이브리드 방식. 그렇게 하면 구독료를 절반 이하로 줄일 수 있어요.

지금 내 맥북의 RAM이 몇 GB인지 확인해보세요. 거기서 이 얘기가 시작돼요.
