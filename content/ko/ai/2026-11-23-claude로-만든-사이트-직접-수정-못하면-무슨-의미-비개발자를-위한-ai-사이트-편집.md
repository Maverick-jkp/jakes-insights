Claude로 사이트 만들었는데, 수정하려니 막막하죠? 개발자 아니면 손도 못 대는 상황, 생각보다 흔해요.

비개발자에게 현실적인 선택지는 **Repaint**와 **ShiftPress** 중 하나예요. 그런데 두 도구의 성격이 꽤 달라서, 잘못 고르면 돈만 쓰고 결국 못 쓰게 돼요.

> **TL;DR**
> - **Repaint 쓰세요, 만약**: Claude artifact를 그대로 가져와서 채팅으로 수정하고 싶을 때, 커스텀 도메인도 바로 연결하고 싶을 때
> - **ShiftPress 쓰세요, 만약**: 이미 완성된 HTML 파일(ZIP)이 있고, 무료로 빠르게 배포만 하고 싶을 때
> - **둘 다 건너뛰세요, 만약**: 팀 단위로 협업하거나 복잡한 기능(회원가입, DB 연동 등)이 필요할 때 — 그럼 Webflow나 Framer가 맞아요

이 글에서 비교할 핵심 기준이에요.
- 가격 (진입 비용)
- 편집 편의성 (비개발자 기준)
- Claude 사이트와의 호환성
- 실제로 망가지는 상황

> **핵심 요약**
> - 2026년 11월 기준, Claude가 만드는 사이트의 절반 이상은 HTML 단일 파일 형태라 Git 기반 CMS로는 편집이 사실상 불가능해요
> - [ShiftPress 2026 연구](https://shiftpress.ai/blog/cms-for-a-website-built-with-claude-code)에 따르면 독일 신규 법인 사이트 중 36%가 CMS 없는 순수 코드 형태로 존재해요
> - Repaint는 Claude artifact를 직접 불러와 채팅으로 수정 → 배포까지 2분 내로 처리해요
> - ShiftPress는 HTML ZIP 업로드 방식으로 무료 시작이 가능하지만 편집 기능이 제한적이에요
> - Git 기반 도구(Decap, TinaCMS, CloudCannon)는 비개발자에겐 진입 장벽이 높아서 현실적인 선택지가 아니에요

## 1. 결론부터: 비개발자라면 Repaint가 앞서요

**Repaint가 이겨요. 편집 편의성과 Claude 호환성 두 가지 모두에서요.**

단, Repaint가 맞지 않는 경우도 있어요. 사이트를 딱 한 번 만들고 수정 없이 배포만 할 거라면, ShiftPress의 무료 플랜이 훨씬 합리적이에요. 월 25달러를 내면서 편집 기능까지 쓸 필요가 없는 거죠.

비교할 네 가지 차원이에요.
- 가격 (진입 비용과 무료 플랜 한계)
- 편집 방식 (채팅 vs 파일 업로드)
- Claude artifact 호환성
- 실패하는 구체적 시나리오

---

## 2. 도구 소개

**Repaint**는 AI 웹사이트 플랫폼이에요. Claude가 만든 HTML이나 React/TSX 코드를 그대로 붙여넣으면, 플랫폼이 그걸 "소스 자료"로 삼아 사이트를 재구성해요. 파일을 그냥 호스팅하는 게 아니라 한 번 더 처리한다는 게 핵심이에요. 편집은 채팅창에 "배경색 흰색으로 바꿔줘"라고 쓰면 되고, 커스텀 도메인도 바로 연결돼요. [Repaint 공식 정보](https://repaint.com/blog/turn-claude-artifact-into-website) 기준으로 14일 무료 체험 후 월 25달러(2026년 11월 기준)예요.

**ShiftPress**는 HTML 파일을 ZIP으로 업로드하면 사이트로 만들어주는 플랫폼이에요. 무료로 시작할 수 있고, 커스텀 도메인은 유료 플랜부터예요. [ShiftPress 2026 분석](https://shiftpress.ai/blog/cms-for-a-website-built-with-claude-code)에서 비개발자를 위한 옵션으로 명시적으로 언급되는 도구예요. 편집보다는 "배포 채널" 역할에 가까워요.

**Git 기반 CMS(Decap, TinaCMS, CloudCannon)**는 비개발자한테는 추천하지 않아요. 콘텐츠를 Markdown/JSON 파일로 먼저 쪼개야 하고, Git 개념도 알아야 하거든요. Claude가 만드는 HTML 단일 파일 형태와는 구조적으로 맞지 않아요.

## 3. 맞대결 비교표

| 비교 항목 | Repaint | ShiftPress | 승자 |
|-----------|---------|------------|------|
| 진입 가격 | 14일 무료 → 월 $25 | 무료 시작, 도메인은 유료 | ShiftPress |
| Claude artifact 직접 가져오기 | HTML/TSX 붙여넣기 즉시 처리 | ZIP 업로드 필요 | Repaint |
| 편집 방식 | 채팅 (자연어) | 파일 재업로드 | Repaint |
| 커스텀 도메인 | 무료 체험 포함 | 유료 플랜부터 | Repaint |
| 버전 관리 | AI 편집 후 롤백 가능 | 미확인 | Repaint |
| 멀티페이지 사이트 | 단일 artifact → 멀티페이지 확장 가능 | 업로드한 페이지 그대로 | Repaint |
| 학습 곡선 | 30분 이내 | 10분 이내 | ShiftPress |

가장 흥미로운 항목은 "편집 방식"이에요. ShiftPress는 엄밀히 말하면 편집 도구가 아니에요. 파일을 다시 올리는 거거든요. 즉, 사이트를 고치려면 Claude한테 다시 물어봐서 새 HTML을 받아서 재업로드해야 해요. 한 번 배포하고 끝이라면 괜찮지만, 꾸준히 관리하는 사이트라면 흐름이 너무 끊겨요.

Repaint의 "재구성" 방식도 짚고 넘어갈 게 있어요. Claude artifact를 그냥 호스팅하는 게 아니라 플랫폼이 한 번 더 처리해요. 덕분에 외부 이미지 URL이 있으면 자동으로 가져와서 저장하고, 문의 폼도 바로 작동하게 돼요. [Repaint 공식 설명](https://repaint.com/blog/turn-claude-artifact-into-website)에 따르면 단순한 사이트 기준 1~2분이면 처리가 끝나요.

가격 면에서는 ShiftPress가 이기는 게 맞아요. 그런데 "무료"의 범위가 달라요. ShiftPress 무료 플랜에서는 커스텀 도메인을 쓸 수 없어요. Repaint는 14일 체험 기간 동안 커스텀 도메인까지 써볼 수 있고요.

## 4. 실제로 망가지는 상황

**Repaint가 한계에 부딪히는 상황**: Claude가 만든 artifact에 복잡한 JavaScript 로직이 포함된 경우예요. Repaint는 사이트를 "재구성"하는 과정에서 일부 커스텀 스크립트나 특수 애니메이션이 의도한 대로 작동하지 않을 수 있어요. 특히 Three.js, WebGL처럼 무거운 라이브러리를 쓴 artifact라면 재구성 후 결과물이 달라질 가능성이 있어요. 월 25달러 내고 "생각한 거랑 다르게 나왔어요"가 나올 수 있는 거죠.

**ShiftPress가 한계에 부딪히는 상황**: 사이트를 반복적으로 수정할 때예요. [ShiftPress 2026 연구](https://shiftpress.ai/blog/cms-for-a-website-built-with-claude-code)에서도 언급했듯이, Claude가 만드는 사이트의 36%는 아코디언, 슬라이더 등 인터랙티브 요소를 포함해요. 이런 요소가 있는 HTML을 계속 Claude에서 수정 받아 재업로드하다 보면, 버전 관리가 전혀 안 되는 상황이 돼요. 세 번째 수정쯤에 "어느 버전이 맞는 거지?"라는 상황이 오거든요.

## 5. 결론 및 다음 단계

다시 정리하면, **Repaint가 비개발자를 위한 Claude 사이트 편집 도구로 더 완성도 있어요.** Claude artifact를 바로 가져와서 채팅으로 수정하고, 커스텀 도메인까지 연결하는 흐름이 끊기지 않거든요. ShiftPress는 "한 번만 배포하고 끝"인 경우에만 현실적인 선택지예요.

**지금 당장 할 수 있는 것**: Claude에서 아무 사이트든 만들어보세요. artifact가 나오면 HTML 코드를 복사해서 Repaint의 14일 무료 체험에 붙여넣어 보면 돼요. 10분이면 흐름 전체를 경험할 수 있어요.

앞으로 주시해야 할 건 하나예요. Claude가 직접 편집 기능을 붙이는 날이 올까요? Anthropic이 claude.site 외에 진짜 배포 기능을 내놓는다면, 이 비교 자체가 의미 없어지거든요. 그 날이 언제 올지가 가장 중요한 질문이에요.
